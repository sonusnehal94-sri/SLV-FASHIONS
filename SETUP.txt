SLV STORE - SETUP, STEP BY STEP
================================
Your publishable key is already inside index.html. You only need to add your Project URL.

PART 1 - DATABASE (Supabase)
 1. Open your Supabase project > SQL Editor > New query.
 2. Open supabase-setup.sql in Notepad. Change YOUR-EMAIL@example.com to your real email. Copy everything.
 3. Paste into the SQL Editor and click Run. It should say Success.
 4. Authentication > Users > Add user > Create new user. Same email, a strong password, tick auto-confirm. This is your admin login.
 5. Authentication > Sign In / Providers > Email: turn OFF "Allow new users to sign up".
 6. Get your Project URL: click the Connect button at the top of the project (or Project Settings > Data API). It looks like https://abcdxyz.supabase.co

PART 2 - ADD THE URL TO THE SITE
 1. Open index.html in Notepad (right-click > Open with > Notepad).
 2. Find this line near the top:
    const CFG={SUPA_URL:'https://tuibbiszefyqapejvlsv.supabase.co',SUPA_KEY:'sb_publishable_...',GMAPS_KEY:''};
 3. Replace PASTE-YOUR-PROJECT-URL-HERE with your Project URL (keep the quotes). Save.

PART 3 - GITHUB
 1. github.com > New repository > name it slv-store > Public > Create.
 2. Click "uploading an existing file". Drag in index.html, README.md and the photos inside the images folder. Commit changes.
 3. Settings > Pages > Source: Deploy from a branch > Branch: main, folder: / (root) > Save.
 4. After 1 to 3 minutes your site is live at https://YOUR-USERNAME.github.io/slv-store/

PART 4 - ADMIN
 1. Open your site address with #admin at the end (or tap the footer SLV logo 5 times).
 2. Log in with the email and password from Part 1, step 4.
 3. Tabs: Dashboard, Live orders, Daily count, Orders, Customers, Reports, Failed orders, Access log.
 4. Download Excel button: top of every admin page.

PART 5 - TEST
 1. On another phone place a Cash on Delivery order.
 2. In admin it should appear in Orders and Live orders within 30 seconds (or press Refresh).
 3. Try a wrong mobile number at checkout. It should appear in Failed orders with the reason.

TROUBLESHOOTING
 - Admin says LOCAL MODE: the Project URL is missing or wrong in index.html.
 - Access denied at login: the email in the SQL must match the user you created in Part 1 step 4.
 - Orders fail with an error: run the SQL again and look for a red error.
 - Never share the secret / service_role key.
